# Loop until empty

The value isn't in the first attack — it's in the fifth. Each round surfaces problems the previous round's polish exposed.

## The loop

```
[copy v1]
    │
    ▼
attack ──► findings ──► fix top 3 ──► [copy v2]
                                          │
                                          ▼
                                      attack ──► findings ──► fix top 3 ──► [copy v3]
                                                                                │
                                                                                ▼
                                                                            attack ──► "nothing significant"
                                                                                              │
                                                                                              ▼
                                                                                          ship it
```

## Rules per round

1. **Fix the top-ranked findings first**, not the ones you agree with. The point is to defeat the objection that loses the most readers, not the one that stings the least.

2. **Rewrite, don't tweak.** If the headline "buries the value prop", write a new headline. Do not soften the old one and call it done.

3. **Attack the whole page each round**, not just the fixed section. A rewrite in the hero changes the flow into the pricing section — new problems appear.

4. **Ignore repeated findings.** If the model calls out the same thing twice, that's the loop working — it means the fix was cosmetic. Actually change it.

5. **Stop only when the model returns "nothing significant to attack" or the remaining findings are subjective taste, not conversion loss.** Do not stop at "I like it now" — that's you polishing, not the reader converting.

## Why looping matters

The first pass surfaces obvious problems (unclear value prop, no CTA, generic testimonials). The second pass surfaces structural problems (order of sections, competing messages). The third and fourth pass surface subtle problems the model couldn't see under the noise of the earlier ones — pricing that reads as suspicious because the guarantee is weak, or a testimonial that undercuts the headline claim.

## Cost sanity

If a page runs for 5 rounds and each round is ~1500 tokens of copy + ~1000 tokens of critique, the whole loop is a rounding error against one paid ad click. Run it.

## When to break the loop

- The model starts suggesting rewrites for taste rather than conversion. Stop.
- The model contradicts an earlier round ("this headline is too short" after saying "this headline is too long"). Stop and use your judgment.
- You've been at it for 30 minutes. Ship v3, watch analytics, iterate on real data.
