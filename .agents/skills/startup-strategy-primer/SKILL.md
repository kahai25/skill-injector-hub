# Startup Strategy Primer

Reference-only skill. When a user asks a strategy question, load the matching reference and answer from it — don't hallucinate MBA-speak.

## When to trigger

- "What's my TAM?" / "How do I size this market?"
- "Should I be worried about competitor X?"
- "Beachhead market" / "adjacent expansion"
- "What's my moat?" / "network effects" / "switching costs"
- "Red ocean" / "blue ocean" / "category creation"
- "Vertical SaaS vs horizontal SaaS" / "platform" / "marketplace" / "aggregator"
- "Is it too early / too late for this?"

- `references/1-market-sizing.md` — TAM/SAM/SOM with a worked example.
- `references/2-beachhead.md` — narrow-then-expand strategy (Amazon books, Facebook Harvard, Tesla Roadster).
- `references/3-moats.md` — the five real moats and how to spot fake ones.

## Non-goals

- Not fundraising advice, not pitch-deck advice, not legal/tax advice.
- Doesn't do market research — provides frameworks, not numbers.
- Doesn't replace talking to actual customers. Frameworks are cheap; conviction comes from customer conversations.
